# 第8周 Day1：柱状图基础与业务表达

## 1. 学习目标

本节开始学习数据可视化，重点掌握如何根据业务问题选择图表，以及如何使用 Matplotlib 绘制基础柱状图。

## 2. 常见图表及用途

- 柱状图：比较不同类别的数值大小。
- 折线图：观察指标随时间的变化趋势。
- 直方图：观察连续数值集中在哪些区间。
- 箱线图：比较中位数、分散程度和异常值候选。
- 散点图：观察两个数值变量之间的关系。
- 堆积柱状图：比较总量及其内部构成。

## 3. 柱状图绘制流程

```text
提出业务问题
-> 选择比较指标
-> 读取并整理数据
-> 按指标排序
-> 设置横轴和柱子高度
-> 添加标题、单位和数据标签
-> 使用颜色突出重点
-> 补充数据范围和指标口径
-> 谨慎解释业务结论
```

## 5. 关键代码结构

```text
读取数据 -> 整理数据 -> 创建画布 -> 绘制图表 -> 添加说明 -> 保存图片
```

柱状图最核心的字段映射是：

```text
横轴字段：比较谁
纵轴字段：比较什么指标
```

## 6. 图表规范

1. 比较绝对数值的柱状图，纵轴通常从0开始。
2. 图表标题、坐标轴名称和单位必须与实际指标一致。
3. 可以使用颜色突出重点，但颜色不等于业务评价。
4. 图表应说明数据范围和指标口径。
5. 不同单位的指标不应直接共用同一个普通纵轴。

## 7. 业务解释与限制

本次分析只包含15笔有效订单，样本量较小。图表只能描述当前数据中的现象，不能证明某个渠道长期表现最好。

评价渠道价值时，还需要结合利润率、退款率、获客成本、用户质量等指标。
