# 第8周 Day3：直方图与数据分布

## 1. 本节学习目标

本节使用15笔有效订单的折扣后销售额，学习如何用直方图观察数值型数据的分布。

主要内容包括：

1. 区分柱状图和直方图；
2. 理解分箱、区间宽度和频数；
3. 比较不同分箱方式对图形的影响；
4. 在直方图中加入均值线和中位数线；
5. 结合偏度描述分布，同时说明样本局限。

## 2. 数据来源与范围

数据文件：

`01_python_pandas/outputs/sales_valid_analysis_week3.csv`

- 中位数销售额：995.00元。

## 3. 柱状图与直方图的区别

柱状图主要用于比较不同类别，例如比较天猫、抖音和京东的销售额。横轴是独立类别，柱子通常存在间隔。

直方图主要用于观察连续数值的分布，例如观察订单销售额集中在哪些金额区间。横轴是连续区间，柱子通常相连。

```python
sales = pd.to_numeric(

```

这段代码将销售额转换为数值，并删除无法参与分布计算的缺失值。

## 5. 500元分箱

第一张直方图使用以下分箱：

```python
bins = [
    0,
    500,
    1000,
    1500,
    2000,
]
```

结果如下：

| 销售额区间 | 订单数量 |
|---|---:|
| 0～500元 | 2笔 |
| 500～1000元 | 6笔 |
| 1000～1500元 | 5笔 |
| 1500～2000元 | 2笔 |

500～1500元共有11笔订单，占全部15笔订单的73.33%。该分箱方式结构简洁，适合说明订单销售额主要集中的大致范围。

## 6. 250元分箱

第二张直方图将区间宽度缩小为250元：

```python
bins = [
    0,
    250,
    500,
    750,
    1000,
    1250,
    1500,
    1750,
    2000,
]
```

结果如下：

| 销售额区间 | 订单数量 |
|---|---:|
| 0～250元 | 0笔 |
| 250～500元 | 2笔 |
| 500～750元 | 3笔 |
| 750～1000元 | 3笔 |
| 1000～1250元 | 5笔 |
| 1250～1500元 | 0笔 |
| 1500～1750元 | 1笔 |
| 1750～2000元 | 1笔 |

250元分箱展示了更多细节，但对于15笔小样本来说图形更加零碎，也更容易受到单笔订单影响。

## 7. 分箱选择原则

分箱不是越多越好：

```text
分箱太少 → 分布细节可能被隐藏
分箱太多 → 图形可能零碎并放大随机波动
```

对于当前15笔订单，500元分箱更适合整体业务汇报，250元分箱更适合查看局部细节。

## 8. 均值、中位数与偏度

在500元分箱直方图中加入了均值线和中位数线：

- 均值：948.94元；
- 中位数：995.00元；
- 偏度：0.5172。

偏度大于0，当前样本存在轻微右偏迹象。右侧的1522.35元和1795.50元等较高订单延长了右侧尾部。

“均值大于中位数通常右偏、均值小于中位数通常左偏”只是一种快速经验，并不是绝对判断规则。小样本、分布不规则及极端值都可能影响均值、中位数和偏度之间的关系。

## 9. 业务结论

在当前15笔有效订单中，500～1500元共有11笔，占73.33%；平均销售额为948.94元，中位数为995.00元，偏度为0.5172，当前样本存在轻微右偏迹象。

由于样本只有15笔，而且直方图形状会受到分箱宽度影响，因此该结果只能描述当前样本，不能直接推广到全部业务订单。

## 11. 本节核心掌握

- 直方图用于观察连续数值分布；
- `bins`决定区间边界；
- 柱高表示落入区间的数据数量；
- 不同分箱可能使同一批数据呈现不同外观；
- 分布解读需要结合均值、中位数、偏度和样本量；
- 观察到的样本现象不能直接推广为总体规律。
