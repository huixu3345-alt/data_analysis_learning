# 第8周 Day5：散点图、变量关系与综合可视化

## 一、学习目标

1. 理解散点图适合观察两个数值变量之间的关系。
2. 理解散点图中每个点代表的观察粒度。
3. 能够判断正相关、负相关和无明显相关。
4. 理解相关关系不等于因果关系。
5. 学会结合样本量和业务因素谨慎解释图表。

## 二、数据范围

本次分析使用15笔有效订单。

筛选条件：

- 订单状态为“已完成”。
- 销售额指标有效。
- `quantity` 和 `net_sales` 不为空。

图表字段：

- 横轴：单笔订单销量 `quantity`。
- 纵轴：单笔订单净销售额 `net_sales`。
- 每个点：一笔有效订单。
- 颜色：销售渠道。
- 点标签：订单编号。

## 三、主要结果

销量与净销售额的相关系数为：

- 相关系数：0.3011
- 关系方向：正相关
- 关系强度：弱相关

这表示在当前样本中，销量较高的订单，其销售额整体上存在上升倾向，但这种关系并不强。

## 四、敏感性检查

为了判断相关系数是否容易受到个别订单影响，进行了简单的敏感性检查：

- 全部15笔订单：0.3011
- 去掉 O1019：0.3270
- 去掉 O1015：0.0972
- 同时去掉 O1019 和 O1015：0.0121

去掉销量最高的 O1015 后，相关系数明显下降，说明当前结果对个别高销量订单较敏感。

O1015 的字段有效，并且业务上合理，因此不应直接删除。正确做法是保留该订单，并在分析结论中说明敏感性。

## 五、业务结论

在当前15笔有效订单中，销量与净销售额呈弱正相关，相关系数为0.3011。

但是，该结果受到个别高销量订单影响，并且销售额还与单价、折扣和商品种类等因素有关，因此不能认定存在稳定关系或因果关系。

## 六、分析限制

1. 当前样本只有15笔有效订单，样本量较小。
2. 销售额同时受到销量、单价、折扣和商品种类影响。
3. 相关系数容易受到个别高销量订单影响。
4. 相关关系不能直接证明因果关系。
5. 当前结果只能描述样本中的现象，不能直接推广到长期业务表现。

- 图表：`outputs/quantity_sales_scatter_week8_day5.png`
- 综合图脚本：`scripts/sales_visual_report_week8_day5.py`

## 八、本日学习总结

散点图适合观察两个数值变量之间的关系。

分析散点图时，需要明确：

1. 横轴和纵轴分别代表什么。
2. 每个点代表什么观察对象。
3. 点的大致方向和分散程度。
4. 是否存在特殊点或高影响点。
5. 样本量是否足以支持稳定结论。
6. 是否还有其他业务因素影响结果。

图表和相关系数只能提供关系证据，不能单独证明因果关系。

## 九、可视化阶段综合练习

本节最后将前面学习的图表组合成一张销售订单综合分析图：

| 分析问题 | 图表形式 | 主要用途 |
|---|---|---|
| 当前整体表现如何 | 指标卡 | 展示有效订单数、总销量、总净销售额和平均每单销售额 |
| 哪个渠道销售额最高 | 柱状图 | 比较不同销售渠道的净销售额 |
| 不同月份销售额如何 | 柱状图 | 比较3个有效月份的净销售额，不用于判断长期趋势 |
| 单笔销售额主要分布在哪里 | 直方图 | 观察不同销售额区间的订单数量 |
| 各渠道的典型水平与波动如何 | 箱线图 | 比较中位数、四分位范围和异常值候选 |
| 销量与销售额是否存在关系 | 散点图 | 观察两个数值变量之间的关系 |

综合分析使用15笔有效订单，其中12笔具有有效月份，月份覆盖率为80%。

主要结果：

1. 天猫净销售额最高，为6,830.65元。
2. 在具有有效月份的订单中，2026年3月净销售额最高，为6,462.00元。
3. 500～1,500元共有11笔订单，占73.33%。
4. 平均每单净销售额为948.94元，中位数为995.00元。
5. 抖音单笔销售额中位数最高；天猫订单金额波动较大。
6. 京东存在一笔箱线图识别出的异常值候选，应保留并进一步核查，不能直接删除。

业务结论：

在当前15笔有效订单中，天猫渠道净销售额最高；在具有有效月份的12笔订单中，3月净销售额最高。但月份覆盖率只有80%，而且只有3个月的数据，因此不能判断长期销售趋势或未来仍会增长。

天猫销售额最高也不等于综合表现最好。综合渠道价值还需要同时考虑利润率、退款率、获客成本和用户质量等指标。

## 十、可视化阶段结课总结

完成本节后，已经能够根据不同业务问题选择并解释以下图表：

- 柱状图：比较不同类别的数值大小。
- 折线图：观察具有足够时间点的连续变化。
- 直方图：观察一个数值变量的分布。
- 箱线图：比较不同分组的典型水平、波动和异常值候选。
- 散点图：观察两个数值变量之间的关系。

完整分析流程为：

```text
业务问题
→ 数据范围和指标口径
→ 选择合适的图表
→ 读取图表直接证据
→ 检查样本量和覆盖率
→ 区分“能够证明”与“不能证明”
→ 输出谨慎的业务结论
```

至此，第8周数据可视化基础课程完成。下一阶段应按照原学习路线进入 BI 学习，而不是把本节重新编号为第9周 Day1。
