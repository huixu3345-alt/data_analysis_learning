## 3. 时间字段处理

原始数据按照月份倒序排列。

绘制折线图之前，需要先把月份转换为日期类型，并按照时间升序排列：

```python
df["order_month"] = pd.to_datetime(
    df["order_month"],
    format="%Y-%m",
)

df = df.sort_values(
    "order_month",
    ascending=True,
).reset_index(drop=True)
```

折线图会按照数据顺序连接各个点，因此时间排序错误会导致图表的时间方向错误。

由于数据只有3个有效月份，只能说明当前样本中的阶段变化，不能据此判断长期趋势或预测未来销售额。

## 5. 环比变化

环比增长金额：

```text
本月销售额 - 上月销售额
```

环比增长率：

```text
（本月销售额 - 上月销售额）÷ 上月销售额 × 100%
```

Pandas代码：

```python
df["sales_growth_amount"] = df["net_sales"].diff()

df["sales_growth_rate"] = (
    df["net_sales"].pct_change() * 100
).round(2)
```

| 月份 | 增长金额 | 环比增长率 |
|---|---:|---:|
| 2026-01 | 缺失 | 缺失 |
| 2026-02 | 346.25 | 13.49% |
| 2026-03 | 3549.95 | 121.91% |

第一个月没有上一个月，因此环比结果为缺失值，这是正常现象。

## 6. 折扣前后销售额对比

折扣前销售额和折扣后销售额的单位都是元，因此适合绘制在同一张折线图中。

```python
df["discount_amount"] = (
    df["gross_sales"] - df["net_sales"]
)
```

| 月份 | 折扣前销售额 | 折扣后销售额 | 折扣影响金额 |
|---|---:|---:|---:|
| 2026-01 | 2696.00 | 2565.80 | 130.20 |
| 2026-02 | 3169.00 | 2912.05 | 256.95 |
| 2026-03 | 7213.00 | 6462.00 | 751.00 |

两条折线之间的距离表示折扣减少的销售金额。

3月折扣影响金额最高，但不能仅凭该图判断3月折扣策略更好，还需要结合销量、利润、订单量、商品结构和促销活动进行分析。

## 7. 图表选择原则

折线图主要用于观察：

- 时间变化；
- 增长与下降；
- 波动情况；
- 多个同单位指标的变化差异。

如果只是比较不同类别的高低，通常优先使用柱状图。

单位不同的指标不应直接共用同一个纵轴。例如销售额的单位是元，销量的单位是件；直接共用纵轴可能产生误导。

## 8. 代码理解要求

本阶段重点理解：

- `sort_values()`：按照时间排序；
- `diff()`：计算与上一行的差值；
- `pct_change()`：计算相对上一行的变化比例；
- `ax.plot()`：绘制折线图；
- `label`和`legend()`：区分多条折线。

复杂的颜色、标签位置和排版代码不要求独立默写，只需要知道用途，并能够复制后修改参数。
