# 第6周 Day3：协方差、相关系数与异常点影响

## 一、学习目标

本次学习两个数值变量之间的共同变化关系，重点区分相关方向、相关强度与因果关系。

主要内容：

- 正相关、负相关和无明显线性相关
- 协方差
- Pearson相关系数
- 多变量相关矩阵
- 单位变化对协方差和相关系数的影响
- 异常点对相关性的影响
- 相关不等于因果

## 二、相关关系

- 正相关：两个变量倾向于同方向变化。
- 负相关：两个变量倾向于反方向变化。
- 相关系数接近0：没有明显线性关系，但不代表完全没有任何关系。

相关系数只能衡量线性关系。两个变量可能存在明确的非线性关系，但线性相关系数仍接近0。

## 三、协方差

协方差主要判断两个变量共同变化的方向：

- 大于0：倾向于同方向变化。
- 小于0：倾向于反方向变化。
- 接近0：没有明显的共同线性变化。

广告投入与销售额示例结果：

```text
协方差 = 479.46
```

协方差为正，说明两个变量倾向于同方向变化。

协方差的大小会受到单位和数据尺度影响，因此不适合直接比较不同变量之间的关系强弱。

## 四、Pearson相关系数

Pearson相关系数范围为-1到1：

- 接近1：强正线性相关。
- 接近-1：强负线性相关。
- 接近0：无明显线性相关。

本次广告投入与销售额的相关系数为：

```text
0.998
```

在当前8条模拟数据中，两者呈非常强的正线性相关。

正确业务表达：

> 当前样本中，广告投入与销售额呈强正线性相关，但仅凭相关系数不能证明增加广告必然导致销售额增长。

## 五、单位变化实验

将广告投入数值扩大1000倍后：

```text
原协方差：479.46
单位变化后的协方差：479464.29
原相关系数：0.998
单位变化后的相关系数：0.998
```

结论：

- 协方差随单位和尺度变化。
- 相关系数经过标准化，不受简单单位缩放影响。
- 比较相关方向和强弱时，相关系数通常比协方差更直观。

## 六、多变量相关矩阵

主要结果：

- 广告投入与销售额：强正相关。
- 价格与销量：强负相关，相关系数约为-0.98。
- 价格与满意度：强负相关，相关系数约为-0.98。
- 销量与满意度：强正相关。

相关矩阵中：

- 对角线为1，因为变量与自身完全相关。
- 上半部分与下半部分信息重复。
- 正负号表示方向，绝对值表示线性关系强弱。

矩阵中显示的1.00可能是保留两位小数后的结果，不一定代表精确等于1。

## 七、相关不等于因果

两个变量相关，不代表其中一个变量导致另一个变量变化。

例如冰淇淋销量和溺水事故可能同时上升，但不能说吃冰淇淋导致溺水。气温可能是同时影响二者的混杂因素。

广告投入与销售额之间也可能受到以下因素影响：

- 季节变化
- 促销活动
- 热销商品获得更多预算
- 市场规模变化

更有力地判断因果关系，可以考虑A/B测试、随机对照实验、对照组以及对混杂因素的控制。

## 八、异常点影响

原始8条数据的相关系数：

```text
0.998
```

加入一条“广告投入100、销售额50”的异常点后：

```text
-0.3688
```

相关结论从强正相关变成较弱的负相关，说明Pearson相关系数对异常点敏感，小样本尤其容易被单条记录影响。

发现异常记录后的正确流程：

```text
检查原始记录
→ 判断是否录入错误
→ 了解特殊业务背景
→ 比较处理前后的结果
→ 记录处理方法
```

不能只因为异常点改变了分析结论就直接删除它。

## 九、数据限制

本次数据只有8至9条，并且是人工构造的模拟数据。极强相关性可能来自数据设计，不能直接外推真实业务规律。

正式分析相关性时，应同时检查：

- 样本量
- 缺失值
- 异常值
- 散点分布
- 非线性关系
- 混杂因素
- 指标的业务含义

## 十一、今日结论

1. 协方差的正负号表示共同变化方向，但数值大小受单位影响。
2. 相关系数范围为-1到1，更适合比较线性关系方向和强弱。
3. 相关系数接近0不等于完全没有关系。
4. 高相关不能直接证明因果关系。
5. 混杂因素可能同时影响两个变量。
6. Pearson相关系数容易受到异常点影响。
7. 相关分析必须结合样本量、数据质量和业务背景进行解释。
