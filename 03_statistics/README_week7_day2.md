# 第7周 Day2：SRM检查、转化率区间与两比例检验

## 一、学习目标

本次学习在读取A/B测试结果后，先检查分流比例，再使用置信区间和两比例Z检验判断转化率差异是否可能来自随机波动。

主要内容：

- 样本比例不匹配SRM
- 卡方分流比例检验
- p-value的正确含义
- 两组转化率置信区间
- 转化率差异置信区间
- 两比例Z检验
- 统计显著性与业务决策

## 二、实验数据

| 组别 | 曝光用户 | 支付用户 | 转化率 |
|---|---:|---:|---:|
| A组 | 5000 | 400 | 8.00% |
| B组 | 5100 | 459 | 9.00% |

观察到的绝对差异为1个百分点，相对提升为12.5%。点估计更高不等于已经证明B组有效。

## 三、样本比例检查

预期分流比例为50/50，总用户数为10100人，因此每组期望人数为5050人。

```text
A组实际人数：5000，偏差-50
B组实际人数：5100，偏差+50
```

SRM检验假设：

```text
H0：实际分流比例符合预期50/50
H1：实际分流比例与预期存在异常差异
```

结果：

```text
卡方统计量：0.9901
SRM p-value：0.3197
显著性水平：0.05
```

因为0.3197大于0.05，当前暂未发现显著SRM异常，可以继续后续分析。

这不表示分流有31.97%的概率正确，也不代表已经证明分流程序绝对没有问题。

SRM异常可能来自：

- 分流程序Bug
- 某个版本加载失败
- 埋点丢失
- 过滤规则对两组影响不同
- 用户重复或错误计数

如果发现明显SRM，应先调查数据和分流问题，不应直接比较转化率。

## 四、两组转化率置信区间

A组：

```text
转化率：8.00%
95%置信区间：7.25%至8.75%
```

B组：

```text
转化率：9.00%
95%置信区间：8.21%至9.79%
```

这些区间分别估计A、B两组真实转化率的可能范围。仅观察两个区间是否重叠，不是判断两组差异显著性的正式方法。

## 五、转化率差异置信区间

定义：

```text
差异 = B组转化率 - A组转化率
```

结果：

```text
观察差异：1.00个百分点
差异标准误：0.55个百分点
差异95%置信区间：-0.09至2.09个百分点
```

业务解释：

> 根据当前样本，B组相对A组的真实转化率差异估计在下降0.09个百分点到提高2.09个百分点之间。

区间包含0，因此不能排除真实没有差异的可能。它不表示B组一定没有效果，只表示当前样本证据还不够确定。

## 六、两比例Z检验

本次使用双侧检验：

```text
H0：A、B真实转化率相同
H1：A、B真实转化率不同
```

结果：

```text
合并转化率：8.50%
Z统计量：1.8013
双侧p-value：0.0717
显著性水平：0.05
```

因为0.0717大于0.05，在5%显著性水平下暂不拒绝原假设。当前数据不足以认定两组真实转化率存在统计显著差异。

p-value不是原假设为真的概率，也不能解释为B组无效的概率。

## 七、置信区间与p-value的一致性

本次结果：

```text
差异95%置信区间包含0
双侧p-value大于0.05
```

两种方法都说明当前证据未达到双侧5%显著性标准。

单侧还是双侧检验必须在实验前确定，不能看到双侧不显著后再临时改用更容易通过的单侧检验。

## 八、统计显著与业务显著

统计显著回答：观察到的差异是否较难用随机波动解释。

业务显著回答：差异是否足够大，能够覆盖开发成本、运营成本和业务风险。

即使统计显著，也不能自动上线，还要检查：

- 绝对提升大小
- 护栏指标
- 实验周期
- 实施成本
- 用户体验
- 长期效果

## 九、结合Day1护栏指标

Day1结果：

```text
退款率增加2.63个百分点，超过允许的1个百分点
错误率增加0.57个百分点，超过允许的0.2个百分点
```

当前实验同时存在：

- 核心指标差异未达到双侧5%统计显著；
- 差异区间包含0；
- 两项护栏指标超过容忍范围。

因此当前新版结算页不应直接上线，应先调查退款率和错误率恶化原因，并评估是否需要修复后重新实验。

## 十、常见误区

1. 肉眼看到49.5%与50.5%就认定分流绝对正常。
2. 把p-value解释为原假设为真的概率。
3. 把p大于0.05解释为已经证明两组完全相同。
4. 只比较两组各自区间是否重叠。
5. 看到B组点估计更高就提前停止实验。
6. 看完结果后切换单侧或双侧检验。
7. 只看统计显著，不看护栏指标和业务价值。
