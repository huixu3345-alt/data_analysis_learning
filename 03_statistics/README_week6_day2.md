# 第6周 Day2：分布形态、百分位数与Z-score标准化

## 一、学习目标

本次学习描述数据分布的形态，理解百分位数的业务含义，并使用Z-score将不同单位的指标转换为可比较的相对尺度。

主要内容：

- 对称分布、左偏分布与右偏分布
- 均值和中位数与偏态的关系
- P25、P50、P75、P90和P95
- 百分位数插值
- Z-score标准化
- 多指标综合得分
- 标准化结果验证

## 二、分布偏态

右偏分布又称正偏分布：

- 大多数数据集中在较低或中等范围；
- 少数较大的数值在右侧形成长尾；
- 通常表现为均值大于中位数。

左偏分布又称负偏分布：

- 大多数数据集中在较高范围；
- 少数较小的数值在左侧形成长尾；
- 通常表现为均值小于中位数。

近似对称分布通常表现为均值接近中位数，但不能只凭二者接近就确认完全对称，还应结合图形观察。

“右偏”不是指大多数数据在右边，而是指少数高值使分布尾部向右侧延伸。

## 三、消费金额分布

本次示例数据：

```text
80，90，100，110，120，130，150，180，250，500
```

统计结果：

- 均值：171
- 中位数：125
- 偏度：2.36

均值明显高于中位数，偏度大于0。大多数金额集中在80至180元，少数250元和500元向右侧形成长尾，因此该数据明显右偏。

偏度判断参考：

- 接近0：大致对称
- 大于0：右偏
- 小于0：左偏

偏度没有绝对统一的业务分界，小样本也容易受单个数值影响，需要结合均值、中位数和图形一起判断。

## 四、百分位数

百分位数表示有多少比例的数据小于或等于该位置。

本次结果：

| 百分位数 | 消费金额 |
|---|---:|
| P25 | 102.5 |
| P50 | 125.0 |
| P75 | 172.5 |
| P90 | 275.0 |
| P95 | 387.5 |

解释：

- P50等于125元，约50%的数据不超过125元。
- P75等于172.5元，约75%的数据不超过172.5元。
- P90等于275元，约90%的数据不超过275元，约10%的数据高于该位置。

百分位数不一定是原始数据中真实存在的数值。pandas会在相邻数据之间进行插值，因此原始数据没有275元也不代表计算错误。

如果暂时使用P90的275元作为高消费门槛，当前原始数据中只有500元进入高消费范围。

P90只是统计参考线，不会自动成为业务上的高价值用户定义。真实分层还应结合购买频率、利润、退款和业务目标。

## 五、Z-score标准化

计算公式：

```text
Z-score =（原始值 − 均值）÷ 标准差
```

含义：

- Z等于0：处于均值。
- Z大于0：高于均值。
- Z小于0：低于均值。
- Z等于2：高于均值2个标准差。
- Z等于-1.5：低于均值1.5个标准差。

Z-score将不同单位和不同数量级的指标转换成无单位的相对位置。

例如消费金额的单位是元，订单数量的单位是单，两者不能直接相加；标准化以后可以比较每个用户在两个指标中高于或低于平均水平的程度。

## 六、用户标准化结果

本次使用5名模拟用户的月消费金额和订单数量，并给两个指标相同权重。

综合排名：

```text
U005 > U002 > U004 > U003 > U001
```

- U005消费金额最高，订单数量也高于平均水平，因此综合得分最高。
- U002消费金额低于平均水平，但订单数量最高，因此综合排名第二。
- U004两个指标总体接近平均水平，综合得分接近0。
- U001两个指标均低于平均水平，因此综合得分最低。

综合得分为负数不代表用户造成亏损，只表示该用户在当前样本、当前指标和当前权重下低于平均水平。

## 七、综合得分限制

本次简单综合得分为：

```text
消费金额Z-score与订单数量Z-score的平均值
```

这表示两个指标各占50%权重，仅用于学习。

真实业务中的用户价值还可能受到以下因素影响：

- 毛利润
- 退款情况
- 跨月复购
- 获客成本
- 最近购买时间
- 用户生命周期

因此，综合得分最高不等于真实业务价值必然最高。指标选择、权重和分层门槛必须根据业务目标确定。

## 十、今日结论

1. 均值高于中位数常提示右偏，均值低于中位数常提示左偏。
2. 偏态方向由长尾方向决定，而不是由大多数数据的位置决定。
3. 百分位数用于描述数据中的相对位置，不一定对应真实出现的原始值。
4. P90可以作为高值门槛的参考，但不是自动成立的业务规则。
5. Z-score表示原始值距离均值多少个标准差。
6. 标准化可以让不同单位、不同量级的指标进入同一比较尺度。
7. 综合评分依赖指标、权重、样本和业务目标，不能脱离业务直接解释。
