# 第6周 Day5：抽样误差、标准误与置信区间

## 一、学习目标

本次学习如何从样本估计总体，并正确描述估计的不确定性。完成本课后，第6周统计学基础结束。

主要内容：

- 总体参数与样本统计量
- 抽样误差
- 标准差与标准误
- 均值的95%置信区间
- 转化率的95%置信区间
- 重复抽样与区间覆盖率
- 随机误差与抽样偏差
- 大样本不能修复有偏抽样

## 二、抽样误差

当总体很大时，通常只能抽取部分对象进行分析。换一批随机样本，样本均值或转化率通常会略有不同。

这种因为随机抽样而产生的估计波动称为抽样误差。

```text
样本统计量是对总体参数的估计
样本统计量通常不完全等于总体参数
```

## 三、标准差与标准误

- 标准差描述单个数据之间有多分散。
- 标准误描述样本统计量在重复抽样中有多不稳定。

均值标准误：

```text
SE = 样本标准差 ÷ √样本量
```

示例：

```text
标准差 = 20
样本量 = 100
标准误 = 2
```

样本量增加到400后，标准误为1。样本量扩大4倍，标准误约缩小为原来的一半。

## 四、均值的95%置信区间

近似公式：

```text
样本均值 ± 1.96 × 标准误
```

本次示例：

```text
样本均值 = 200
样本标准差 = 50
样本量 = 100
标准误 = 5
误差范围 = 9.8
95%置信区间 = [190.2，209.8]
```

正确解释：如果使用相同方法重复抽样并构造置信区间，长期来看，大约95%的这些区间会覆盖真实总体均值。

置信区间不表示95%的用户数据位于这个区间。

## 五、转化率的95%置信区间

本次示例：

```text
访客数 = 1000
购买人数 = 80
样本转化率 = 8%
```

转化率标准误近似公式：

```text
SE = √[p × (1 - p) ÷ n]
```

结果：

- 标准误约为0.0086；
- 误差范围约为1.68个百分点；
- 95%置信区间约为6.32%至9.68%。

只报告8%的点估计不够，还需要说明样本量和估计不确定性。

## 六、重复抽样模拟

从均值200、标准差50的总体分布中重复抽样10000次。

结果：

| 样本量 | 理论标准误 | 模拟标准误 |
|---:|---:|---:|
| 100 | 5.00 | 4.97 |
| 400 | 2.50 | 2.51 |

模拟结果接近理论值，验证了标准误公式。

样本量100的95%置信区间覆盖率为94.88%，接近理论上的95%。模拟覆盖率不会每次精确等于95%，因为有限次数模拟仍有随机波动。

## 七、样本量与区间宽度

在其他条件不变时：

- 样本量越大，标准误越小；
- 标准误越小，置信区间越窄；
- 数据标准差越大，标准误越大；
- 置信水平越高，区间通常越宽。

样本量增加可以减少随机误差，但不能自动修复数据质量或抽样偏差。

## 八、随机样本与VIP偏差样本

模拟总体由以下用户组成：

- 80%普通用户，平均消费约100元；
- 20%VIP用户，平均消费约500元。

结果：

```text
总体平均消费：179.98元
随机样本平均消费：178.37元
VIP偏差样本平均消费：499.28元
随机样本标准误：1.61
VIP偏差样本标准误：0.50
```

随机样本均值接近总体均值。VIP样本标准误更小，看起来非常稳定，但因为只包含VIP用户，无法代表全部用户。

这种情况可以概括为：

```text
精确但有偏
```

标准误只衡量随机波动，不会自动发现样本代表性问题。

## 九、随机误差与系统偏差

随机误差：

- 来自随机抽样；
- 换一批样本会发生波动；
- 通常可以通过增加合格样本量降低。

系统偏差：

- 来自抽样范围、收集方法或指标定义；
- 例如只调查VIP用户；
- 增加同类偏差样本不会解决问题。

正确顺序是先保证样本具有代表性，再考虑扩大样本量。

## 十、与A/B测试的连接

A方案转化率8%，B方案8.5%，不能只看0.5个百分点差异就宣布B获胜。

还需要判断：

- 两组样本量是否足够；
- 分组是否随机；
- 置信区间是否过宽；
- 差异是否可能来自随机波动；
- 指标口径是否一致；
- 实验期间是否受到其他因素干扰。

这些问题将在第7周A/B测试中继续学习。

本周已完成：


统计分析不只是计算一个数字，还要同时说明：

- 数据来自哪里；
- 样本是否有代表性；
- 指标如何定义；
- 估计有多大不确定性；
- 结论能否推广到总体；
- 结果是否支持因果判断。
