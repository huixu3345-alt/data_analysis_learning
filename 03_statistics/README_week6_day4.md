# 第6周 Day4：概率、期望值与二项分布

## 一、学习目标

本次学习概率在业务分析中的基本含义，并使用二项分布和随机模拟分析转化人数与活动收益风险。

主要内容：

- 随机事件与概率
- 补事件
- 互斥事件与独立事件
- 期望值
- 二项分布
- 理论结果与随机模拟
- 盈亏平衡点
- 收益分布与风险解释

## 二、概率基础

概率表示事件发生的可能性，范围为0到1，也可以写成0%到100%。

```text
事件发生概率 = 事件发生次数 ÷ 总观察次数
```

例如1000名访客中80人购买，估计购买概率为8%。这不表示下一批100名访客一定恰好有8人购买，而表示长期重复观察时购买比例倾向于接近8%。

补事件概率：

```text
P(不购买) = 1 - P(购买)
```

## 三、互斥事件与独立事件

互斥事件不能在同一次观察中同时发生。例如一笔订单的最终状态只能是已完成或已取消。

独立事件可以同时发生，但一个事件是否发生不影响另一个事件的概率。例如假设不同用户是否购买彼此独立。

```text
互斥：不能同时发生
独立：可以同时发生，但互不影响
```

两个独立事件同时发生的概率：

```text
P(A且B) = P(A) × P(B)
```

## 四、期望值

期望值表示大量重复情况下，每次随机结果的长期平均水平。

```text
期望值 = 各结果 × 对应概率，然后求和
```

期望收益为正不表示每一次都会盈利。实际单次结果仍可能亏损，需要同时分析收益波动和风险承受能力。

## 五、二项分布

简单二项分布通常要求：

1. 试验次数固定；
2. 每次只有成功或失败两种结果；
3. 每次成功概率相同；
4. 各次试验近似独立。

本次业务场景：

```text
每批用户数 n = 100
单名用户购买概率 p = 0.08
```

理论结果：

- 期望购买人数：8人
- 方差：7.36
- 标准差：2.71人
- 恰好8人购买的概率：14.55%
- 至少1人购买的概率：99.98%

期望购买人数为8，不代表实际一定恰好有8人购买。成功次数会围绕期望值随机波动。

## 六、10000次随机模拟

使用固定随机种子模拟10000批用户：

```python
rng = np.random.default_rng(42)
rng.binomial(n=100, p=0.08, size=10000)
```

随机种子42用于保证结果可以复现，不是业务参数。

模拟结果：

- 模拟平均购买人数：7.98人
- 模拟标准差：2.72人
- P5购买人数：4人
- P50购买人数：8人
- P95购买人数：13人

模拟均值和标准差接近理论结果，说明大量重复模拟后，平均表现会趋近理论期望。

P5为4、P95为13表示约5%的模拟批次购买人数不超过4人，约95%的批次不超过13人，中间约90%的批次位于4至13人之间。

## 七、活动收益分析

假设：

- 每名用户触达成本：5元
- 每名购买用户贡献：80元
- 每批触达用户：100人
- 每名用户购买概率：8%

每名用户期望收益：

```text
0.08 × 80 - 5 = 1.4元
```

每批100名用户理论期望收益：

```text
100 × 1.4 = 140元
```

每批总成本为500元，每名购买用户贡献80元，因此至少需要7人购买才能盈利。

## 八、收益模拟结果

- 模拟平均收益：138.35元
- 收益标准差：217.28元
- 批次盈利比例：69.29%
- 批次不盈利比例：约30.71%
- P5收益：-180元
- P50收益：140元
- P95收益：540元
- 模拟最低收益：-420元
- 模拟最高收益：1180元

虽然理论期望收益为正，但仍有约30.71%的批次不盈利。这说明决策不能只看平均收益，还要考虑风险分布和公司的风险承受能力。

P5为-180元表示约5%的模拟批次收益不超过-180元，也就是亏损至少180元。

## 九、NumPy与pandas的分位数方法

本次脚本中的模拟结果是NumPy数组，因此应使用：

```python
np.quantile(simulated_batch_profit, 0.05)
```

pandas Series则可以使用：

```python
series.quantile(0.05)
```

NumPy的`ndarray`没有`.quantile()`方法。应先确认对象类型，再选择对应写法。

## 十、数据限制

本次概率8%、用户贡献80元和触达成本5元均为学习用假设。真实业务中还需要考虑：

- 用户购买概率是否相同；
- 用户行为是否独立；
- 概率估计是否来自足够样本；
- 不同用户的客单价和利润差异；
- 退款、优惠和履约成本；
- 活动长期用户价值。

因此，模拟结果用于理解方法，不能直接作为真实投放决策。

## 十二、今日结论

1. 概率描述长期发生倾向，不保证单次结果。
2. 互斥事件不能同时发生，独立事件互不影响。
3. 期望值是长期平均，不是下一次必然结果。
4. 二项分布用于固定次数、两种结果、固定概率且近似独立的试验。
5. 理论期望和模拟平均在大量重复下会接近。
6. 期望收益为正仍可能出现大量亏损批次。
7. 业务决策应同时考虑平均收益、波动、极端风险和数据假设。
