# 第6周 Day1：描述性统计基础

## 一、学习目标

本次学习从 SQL 阶段过渡到统计学阶段，重点理解如何描述一组业务数据的中心位置、波动程度和异常值候选。

主要内容：

- 总体、样本与变量
- 数值型变量与类别型变量
- 均值、中位数与众数
- 极差、方差与标准差
- 四分位数与 IQR
- 极端值对统计指标的影响
- 使用 pandas 生成描述性统计结果

## 二、总体、样本与变量

- 总体：真正希望研究的全部对象。
- 样本：从总体中实际抽取并分析的部分对象。
- 变量：记录在每个对象身上的特征。

变量可分为：

- 数值型变量：消费金额、年龄、订单数量等。
- 类别型变量：城市、渠道、会员等级等。

样本结果不等于总体事实。如果样本选择方式存在偏差，例如只调查 VIP 用户，分析结果就可能无法代表全部客户。

## 三、集中趋势

本次使用的示例消费金额：

```text
100，120，120，150，1010
```

结果：

- 均值：300
- 中位数：120
- 众数：120

均值适合描述所有数据的算术平均水平，但容易受到极端值影响。中位数适合描述排序后处于中间位置的典型水平，对极端值更稳健。

均值并不是不可靠，而是回答的问题不同：

- 均值回答“平均每名用户贡献多少金额”。
- 中位数回答“处于中间位置的典型用户消费多少”。

## 四、离散程度

示例数据：

```text
A组：80，90，100，110，120
B组：98，99，100，101，102
```

两组均值和中位数都是 100，但离散程度不同：

| 指标 | A组 | B组 |
|---|---:|---:|
| 均值 | 100.00 | 100.00 |
| 中位数 | 100.00 | 100.00 |
| 极差 | 40.00 | 4.00 |
| 样本方差 | 250.00 | 2.50 |
| 样本标准差 | 15.81 | 1.58 |

A组标准差更大，说明数据更加分散；B组标准差更小，说明数据更加集中稳定。

pandas 的 `var()` 和 `std()` 默认计算样本方差和样本标准差。标准差的单位与原数据相同，通常比方差更容易进行业务解释。

## 五、极端值的影响

包含 1010 时：

- 均值：300.00
- 中位数：120.00
- 样本标准差：397.30

暂不包含 1010 时：

- 均值：122.50
- 中位数：120.00
- 样本标准差：20.62

1010使均值和标准差明显增大，但中位数没有变化。这说明均值和标准差对极端值敏感，而中位数更稳健。

敏感并不代表指标错误。是否保留极端值，需要结合业务背景判断。

## 六、describe 描述性统计

`describe()`可以一次生成：

- count：有效数据数量
- mean：均值
- std：样本标准差
- min：最小值
- 25%：第一四分位数
- 50%：中位数
- 75%：第三四分位数
- max：最大值

本次消费金额的结果：

| 指标 | 数值 |
|---|---:|
| count | 5.00 |
| mean | 300.00 |
| std | 397.30 |
| min | 100.00 |
| 25% | 120.00 |
| 50% | 120.00 |
| 75% | 150.00 |
| max | 1010.00 |

均值明显高于中位数，说明结果受到高消费值影响。

## 七、IQR 异常值候选检查

计算结果：

```text
Q1 = 120
Q3 = 150
IQR = 30
下界 = 75
上界 = 195
```

1010超过上界195，因此被IQR规则标记为异常值候选。

正确处理流程：

```text
统计规则发现候选值
→ 查看原始记录
→ 结合业务含义判断
→ 决定保留、修正、单独分析或删除
→ 在报告中记录处理方法
```

异常值候选不等于错误数据。1010可能是真实高价值客户、团购订单、异常交易或录入错误，不能只根据统计规则直接删除。

## 九、今日结论

1. 总体是希望研究的全部对象，样本是实际分析的部分对象。
2. 均值、中位数和众数描述数据的中心，但适用问题不同。
3. 两组均值相同，不代表数据波动和业务表现相同。
4. 标准差越大，数据越分散；标准差越小，数据越集中。
5. 极端值会明显影响均值和标准差，但不一定是错误数据。
6. IQR只能识别异常值候选，最终处理必须结合业务含义。
7. 统计分析不仅要计算指标，还要明确统计单位、样本范围和数据限制。
