# 统计学基础速查表

## 一、先判断问题属于哪一类

```text
描述当前数据是什么样 → 描述性统计
用样本估计总体 → 推断统计
```

描述性统计主线：

```text
数量 → 中心 → 波动 → 形状 → 异常 → 关系
```

推断统计主线：

```text
样本统计量 → 标准误 → 置信区间 → 判断代表性
```

## 二、看到业务问题时选择指标

| 业务问题 | 优先想到的指标 |
|---|---|
| 有多少有效数据 | count |
| 平均每名用户贡献多少 | 均值 mean |
| 普通典型用户处于什么水平 | 中位数 median |
| 最常出现的类别或数值 | 众数 mode |
| 数据差异和波动有多大 | 标准差 std |
| 数据覆盖范围有多大 | 极差 max - min |
| 25%、50%、75%的位置 | Q1、Q2、Q3 |
| 最高约10%的分界位置 | P90 |
| 分布是否偏斜 | 均值、中位数、偏度 |
| 是否有异常值候选 | IQR上下界 |
| 两个变量是否一起线性变化 | 相关系数 corr |
| 不同单位指标如何比较 | Z-score标准化 |
| 样本均值估计有多不稳定 | 标准误 SE |
| 总体参数的可能估计范围 | 置信区间 CI |

## 三、中心位置

### 均值

```text
所有数值之和 ÷ 数据量
```

适合回答：平均每名用户贡献多少销售额。

特点：使用全部数据，但容易受到极端值影响。

### 中位数

排序后位于中间位置的值。

适合回答：普通典型用户大约处于什么水平。

特点：对极端值更稳健。

### 众数

出现次数最多的值或类别。

适合回答：用户最常来自哪个城市、最常购买哪个商品。

## 四、波动程度

### 极差

```text
最大值 - 最小值
```

只看两个端点，容易受极端值影响。

### 方差

衡量数据偏离均值的总体程度，单位是原单位的平方。

### 标准差

方差开平方，单位与原数据相同。

```text
标准差大 → 数据更分散
标准差小 → 数据更集中
```

两组均值相同，不代表波动程度相同。

## 五、分布形状

### 右偏

```text
少数高值使尾部向右延伸
通常均值 > 中位数
```

常见于收入、订单金额和用户消费额。

### 左偏

```text
少数低值使尾部向左延伸
通常均值 < 中位数
```

### 对称

均值通常接近中位数，但不能只凭这一点确认完全对称。

## 六、百分位数

```text
P90 = 约90%的数据不超过这个位置
```

P90以上大约是最高的10%。

百分位数是统计位置，不一定是原始数据中真实出现的数值，pandas可能在相邻数据之间插值。

P90可以作为业务门槛参考，但不会自动成为高价值用户定义。

## 七、IQR异常值候选

```text
IQR = Q3 - Q1
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR
```

超出上下界的数据是异常值候选，不等于错误数据。

处理流程：

```text
发现候选 → 检查原始记录 → 结合业务判断
→ 决定保留、修正、单独分析或删除 → 记录处理方法
```

## 八、Z-score标准化

```text
Z =（原始值 - 均值）÷ 标准差
```

- Z等于0：处于均值。
- Z大于0：高于均值。
- Z小于0：低于均值。
- Z等于-1.5：低于均值1.5个标准差。

Z-score将不同单位的指标变成无单位的相对位置。

综合评分仍然依赖指标选择和权重，不能自动代表真实业务价值。

## 九、协方差与相关系数

### 协方差

- 正数：倾向于同方向变化。
- 负数：倾向于反方向变化。
- 数值大小受单位影响。

### 相关系数

范围为-1到1：

- 接近1：强正线性相关。
- 接近-1：强负线性相关。
- 接近0：无明显线性相关。

```text
相关接近0 ≠ 完全没有关系
高相关 ≠ 存在因果关系
```

相关分析还要检查样本量、异常值、非线性关系和混杂因素。

## 十、标准差与标准误

| 指标 | 回答的问题 |
|---|---|
| 标准差 SD | 单个数据之间有多分散 |
| 标准误 SE | 样本统计量在重复抽样中有多不稳定 |

均值标准误：

```text
SE = 样本标准差 ÷ √样本量
```

样本量扩大4倍，标准误通常缩小为原来的一半。

## 十一、95%置信区间

均值的近似95%置信区间：

```text
样本均值 ± 1.96 × 标准误
```

正确含义：如果重复抽样并用相同方法构造区间，长期约95%的区间会覆盖真实总体参数。

它不表示95%的用户数据位于区间中。

样本量越大，标准误通常越小，置信区间越窄。

## 十二、随机误差与抽样偏差

```text
增加合格样本量 → 可以降低随机误差
增加有偏样本量 → 不能修复抽样偏差
```

只调查VIP用户，即使有10万人，也不能代表全部用户。

标准误很小只表示结果稳定，不保证样本具有代表性。

